# 项目工作日志（Project Work Log）

## 0. 核心循环

> 动手前先读日志尾；每完成一步追加一行；会话结束补终态行。

规范性用语：**必须**（MUST，违反即缺陷）/ **禁止**（MUST NOT）/ **应**（SHOULD，偏离需理由）/ **可以**（MAY）。

## 1. 首次运行检查（会话内首次修改项目文件前，必须）

1. 按第 2 节顺序定位项目手册。
2. 在手册中找 `## 工作日志` 节：
   - 找到 → 只读该节**最后 ≤40 行**，恢复三件事：上次做到哪、遗留问题、已知坑；然后继续任务。
   - 未找到 → 按第 2 节新建日志节（手册也没有 → 同时新建最小手册）。
3. 引导动作本身记为本次会话的第一条日志。
4. 本会话纯属问答、不动任何项目文件 → 跳过整个 skill（不读不写，省 token）。

## 2. 手册与日志节的定位 / 引导

手册发现顺序（取第一个命中）：

1. 根目录或 `docs/` 下的 `PROJECT_OVERVIEW*.md`、`MANUAL*.md`、`项目手册*.md`；
2. README 中明确声明为「项目手册」的链接；
3. 都没有 → 新建 `PROJECT_OVERVIEW.md`，仅含两节：`# 项目手册`（一两句话简介）+ `## 工作日志`。

日志节规则：

- 固定二级标题 `## 工作日志`，置于手册**文件末尾**；
- 新建时禁止打乱、删除、改写手册既有章节；
- 多个会话块按时间正序向下追加。

## 3. 日志格式（唯一格式，不要自由发挥）

每次会话 = 一个会话块；每一步 = 块内一行。

```markdown
### 2026-09-13 00:52 +08 · 会话 3f9a1c2e · 修复设置页崩溃
- 00:52 复现崩溃：冷启进设置页必现（源:命令:adb logcat）
- 00:57 定位 NPE 根因：mBinder 未初始化（源:文件:app/src/…/SettingsActivity.kt:88）
- 01:03 改 lazy 初始化 + 空保护；build 通过、12 项测试全绿（源:步骤2）
- 01:10 提交 a1b2c3d「fix: lazy-init binder」（源:命令:git commit）
- 01:10 终态: done
```

硬性规则：

- **会话头**：完整日期 + 起始 `HH:MM` + UTC 偏移 + 会话标识前 8 位（取不到写 `local`）+ ≤20 字任务主题。
- **每行**：`HH:MM 动词开头的动作 → 结果（源:<标签>）`，≤120 字符，与会话头同时区。
- **每行必有 `（源:…）`**，标签只能取：`用户请求`｜`文件:路径[:L行]`｜`命令:<摘要>`｜`测试`｜`web:<域名>`｜`记忆`｜`步骤N`（N 为本块内上一步序号，按出现顺序 1 起算）。
- **时间取真实时钟**（time 工具或 `date '+%F %H:%M %z'`），禁止编造；同一分钟内多行可共用 `HH:MM`。
- 会话块最后一行必须为 `终态: done|blocked|cancelled`；blocked 附一句原因。

## 4. 写入节奏与 token 经济（本 skill 存在的理由）

- **记完成的，不记计划的**：一步有了可验证产出才记一行；read/grep 等无结论的信息获取并入下一步那一行，不单独记。
- **微步合并**：2–3 个连续微操作合并成一行是应尽义务，不算丢步。
- **追加写入**：用 edit 以日志节末行（或上一会话块末尾）为锚点向下追加；禁止 write 重写整个手册；禁止为写日志重读手册——取锚点只读文件尾部（read 带 offset）。
- **批量落盘**：连续快步允许攒 2–3 行一次 edit 写入；终态行缺失时，下次会话首条日志写 `续: 上次未收尾`。
- 单会话块 ≤30 行；超出 = 记得太碎，应回头合并。
- **日志不承载知识**：值得长期保留的结论写进手册正文或独立文档，日志只留一行指针（如 `详见 docs/X.md`）。

## 5. 内容红线（禁止进日志）

- 代码、配置、报错全文——用 `路径:行号`、commit hash、一句结论代替；错误关键信息摘引 ≤80 字符。
- 思考过程、方案对比、计划展望、寒暄、自我评价。
- git 已有的 diff 细节——只写 hash 与一句话意图。
- 失败尝试 = 1 行「试 X 失败（原因）→ 改走 Y」，不展开。

## 6. 收尾自检（会话结束前，应）

- [ ] 首次运行检查已完成，日志尾已读？
- [ ] 每行 = 时间 + 动作 + 结果 + 来源？有终态行？
- [ ] 本会话块 ≤30 行？无代码/报错全文？
- [ ] 长期结论已挪出日志、只留指针？
