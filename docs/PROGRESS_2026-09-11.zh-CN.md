## 2. 关键发现（踩坑记录）

1. **`WindowInsets.getWaterfallInsets()` 是 @hide**：公开 SDK 只有 `DisplayCutout.getWaterfallInsets()`（API 29+），编译期就会炸，已绕行。
2. **无窗口进程（A11y 服务）的 WindowMetrics 不暴露 waterfall side insets**：即使 dumpsys 有值也采不到 → 覆盖层全屏窗口（NO_LIMITS+SHORT_EDGES）的 `OnApplyWindowInsets` 回调才是公开可达通道（已实现回填）。
3. **模拟器 cutout emulation 用 `cmd overlay enable` 生效**，无需改 AVD config；waterfall emulation 的 cutout rects 为空但 side insets=53（双通道都要采）。
4. **构建后 APK 大小巧合相同（112821 bytes）**：ZIP 大小不可信，必须 `strings classes.dex | grep` 验证（本项目铁律再次应验）。
5. 模拟器 headless 跑任务可行：uiautomator dump 定位控件 → `input tap` 输入任务 → engine.log 观察。
