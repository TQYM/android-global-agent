# 豆包交互规格无障碍化适配（agent-lite）

> 依据《豆包手机助手人机交互模式分析与复刻规格说明书》（2026-09-06，~/Downloads/Kimi_Agent_手机操作技能评测 (3)/）
> 对 `agent-lite` 的交互层改造。约束：**必须纯无障碍模式可行，零 root**。
> 实施日期：2026-09-06。实测设备：荣耀 YLP-W00（Android 17，无 root）。

---

## 1. 关键使能点

`TYPE_ACCESSIBILITY_OVERLAY`：无障碍服务可直接创建覆盖层窗口，**无需 SYSTEM_ALERT_WINDOW 权限**。
报告的「代理可见性三信号」因此全部可在零 root 下复刻。

## 2. 规格 → 实现映射

| 报告规格 | 无障碍模式判定 | 实现 |
|---|---|---|
| 灵动岛胶囊（任务锚点/进展/点按展开） | ✅ | `OverlayController` 顶部黑色胶囊：粉👆 + 动作文案 + 加载环；点击展开面板（补充输入 / ⏸接管▶交还 / ⛔停止 / 收起） |
| 粉色边缘光晕（呼吸式） | ✅ | 四边渐变 View + 1.8s 呼吸动画；接管即熄灭、仅留素色边框（光晕消/边框留二值信号） |
| 接管卡片（红手指/请手动操作/粉色主按钮/补充停止常驻） | ✅ | 底部白卡片（WRAP_CONTENT 底部锚定，卡片外不挡触摸，用户可直接操作手机） |
| 三层授权（事前/事中/事后） | ✅ | 事前：操作类型×App 作用域三选项弹窗（单次/始终/拒绝），「始终允许」持久化可撤回；事中：胶囊+光晕+停止常驻；事后：任务归档 + 授权管理页 |
| 敏感分级强制接管（支付/协议/验证码/权限弹窗） | ✅ | `SensitiveGuard` 每步扫描节点关键词，命中即暂停+接管卡片；交还后一步内免扫描防同页重触发 |
| 生态封锁三档（可全自动/可登录不可操作/完全封锁） | ✅ | `EcoPolicy` JSON 清单数据化（默认=报告 2025-12-10 新京报实测快照），任务文本预检 + `app` 动作强制检查；二档有替代 App 自动切换（高德→百度）；生态页点按改档 |
| 完成卡片（绿色、摘要+产物、禁罗列步骤） | ✅ | `showDone` 绿色 ✓ 卡片持久展示；SCHEMA 约束 summary 只写结论 |
| 失败话术范式（任务失败——+实验室功能定位+归因） | ✅ | `failTask()` 统一出口；新增 `fail` 动作供模型主动归因；超时/卡死/断连同走该出口 |
| 任务归档（可回查可清除） | ✅ | `TaskHistory` JSONL（完成/失败/终止 + 摘要 + 步数），「历史」页查看/清空 |
| 记忆「记一下」+ 静默调用 | ✅ | 任务框「记一下…」前缀写入 `MemoryStore`；系统提示词静默注入（明示模型不披露）；「记忆」页查看/删除/清空 |
| 澄清话术（具体选项收尾、禁止开放式反问） | ✅ | SCHEMA 规则追加 |
| 补充通道（执行中追加指令） | ✅ | 胶囊面板输入框 → 队列 → 下一步注入「用户补充：…」消息，任务不中断 |
| 虚拟屏双空间 / 后台并行 | ❌ root 限定 | 同语义替代：真屏执行 + 光晕/胶囊信号 + 一键暂停接管 |
| 物理 AI 键 / 声纹 / 耳机 / 锁屏 AI 空间 | ❌ 系统级能力 | 放弃（报告允许的路线差异） |

## 5. 已知边界（如实呈现）

- 无障碍模式 AI 在真屏操作：执行期间用户与 AI 共用一块屏，无法后台并行；以「随时暂停接管」补偿。
- 覆盖层会出现在 AI 的感知截图中：SCHEMA 已告知模型忽略光晕/胶囊；若特定 ROM 的 takeScreenshot 排除覆盖层则更干净。
- 敏感守卫是关键词规则，存在误伤/漏检空间；支付确认同时由模型 ask 兜底（双层）。
- 生态清单是历史时点快照，需按生态变化维护（生态页可改档）。
