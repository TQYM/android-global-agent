# Agent Lite 适老化前端改版（手机形态）

> 项目：`agent-lite`（镜像 `agent-unified/client` 已同步）· 2026-10-30 · 门禁 `tests/elder_ui_guard.py`

## 1. 目标与边界

**面向人群**：老年人，以及视力、手部或识字能力不便、不熟悉手机操作的人。
**要求**：简单易懂、使用门槛低；**全部功能与基本能力保持不变**。

| 改了什么 | 没改什么 |
|---|---|
| 手机形态的 5 个页面布局（主页 / 设置 / 登录 / 充值 / 语音召唤抽屉） | 引擎、感知、执行、账号、同步、计费等全部业务逻辑 |
| 手机形态主题：深色 → 浅色高对比 | 手表形态（`activity_main_watch` / `activity_watch_settings` / 新拆出的 `activity_login_watch` 即原布局）|
| 系统对话框与悬浮卡片的字号、触控尺寸 | 悬浮层窗口类型、触摸标志、出现/撤下时机（避免重新引入「吃点击」类缺陷）|
| 用户可见文案改为口语化说明 | 控件 id：改版前各页面的 id 一个不少（门禁 E-1）|

零 root 底线不受影响：本次没有新增或改动任何 root 路径。

## 2. 设计规则

依据工信部《移动互联网应用（APP）适老化通用设计规范》与 WCAG 2.1 AA，令牌集中在
`agent-lite/res/values/elder.xml`，样式在 `res/values/styles.xml` 的 `Elder.*`：

- **字号**：正文 20sp、按钮 24sp、主按钮 28sp、标题 30sp，最小不低于 18sp；全部用 sp，叠加系统字体放大。
- **触控**：常规按钮 ≥ 64dp，「我要说话」96dp、「开始 / 停止」80dp，输入框 ≥ 72dp。
- **不写死高度**：控件一律 `minHeight`，系统字体调到最大时整行换行而不是被裁字。
- **对比度**：正文 ≥ 7:1，按钮与状态文字 ≥ 4.5:1，边框 ≥ 3:1（16 组色对由门禁实算）。
  适老化色板**不跟随莫奈动态取色**（动态色无法保证对比度）。
- **一屏一条路**：主页自上而下 = 看状态 → 说话 / 打字 → 开始 → 看提示；不常用功能放下方。
- **图标 + 文字**：主要按钮带 Material 图标（Apache-2.0 矢量路径），不只靠文字或只靠图标。
- **看得见的反馈**：按钮点下去必有大字提示（改版前很多反馈只写进隐藏日志）。
- **防误触**：清空 / 重置 / 收回全部类操作先二次确认，危险按钮红字。

## 3. 逐页对照（功能保持表）

### 主页 `activity_main.xml` + `MainActivity`

| 改版前 | 改版后 | 说明 |
|---|---|---|
| 顶栏「设置」小按钮 | 「设置」大按钮 + 图标 | 同 `btnConfig` |
| 状态胶囊「空闲 / 运行中 · 第 N 步」 | 状态卡大字「准备好了，请告诉我要做什么」/「正在帮您操作…（第 N 步）」 | 同 `tvStatus`；未开无障碍时显示「还差一步」，与横幅一致 |
| 无障碍胶囊 | 状态卡第二行，绿底 / 红底，**可点直达系统设置** | 同 `tvA11y` |
| 无障碍横幅 + 「一键开启」 | 琥珀色提醒卡「还差一步」+ 逐字说明 + 「去打开开关」 | 同 `a11yBanner` / `btnA11yBanner` |
| 输入框 + 「语音」+「运行」挤在一行 | 「我要说话」最大主按钮在上；输入框单独一行；「开始」整行 | 同 `btnMic` / `etTask` / `btnRun`；录音中按钮变红「说完了，点这里」，识别中置灰 |
| — | 「试试这样说」4 个例句（声音调大 / 屏幕调亮 / 打开微信 / 帮我记住） | **只填进输入框**，由用户自己点「开始」；「帮我记住」填入「记一下：」走原有显式记忆通道 |
| 运行中「运行」改「停止」 | 同一位置变成红色「停止」+ 停止图标 | 同 `btnRun` |
| 反馈只进隐藏日志 / 两秒 Toast | 大字提示框 `tvLastMsg`（新增）常驻显示最近一条 | 引擎技术日志仍不展示（守则 T-4） |
| 四宫格「历史记录 / 授权管理 / 省电策略 / 记忆库」 | 四个整行入口块，标题 + 一句话说明：做过的事 / 授权管理 / 应用限制 / 记住的事 | 同 4 个 id；「省电策略」实为生态清单（应用自动化档位），按实际含义改名 |
| 账号状态行 | 底部账号入口块，三态（未登录 / 已过期 / 剩余额度）用语义色 | 同 `tvAccount` |
| 截屏回显、日志 | 仍隐藏保留 | 同前一版需求 |

对话框：首次说明、凭据解决卡、提问、登录失效、四个管理弹窗全部经 `ElderUi.show` 放大（标题 24sp、
正文 20sp、按钮 ≥64dp，危险按钮红字）；列表弹窗从 `setItems` 换成 `ElderUi.list`（每项 20sp、≥64dp、
长文案换行不截断）。清空记录 / 收回全部授权 / 清空操作记忆 / 恢复默认档位新增二次确认。

### 设置页 `activity_settings.xml` + `SettingsActivity`

- 上半页「常用」：**我的账号**（登录 / 充值 / 刷新额度 / 兑换码 / 设备列表 / 退出登录）、
  **让小帮手正常工作**（①无障碍 ②自启动 ③后台不限制，按顺序编号）。
- 下半页「高级设置」默认收起（新增 `btnAdvanced` / `advancedGroup`），内含原样的模型与接口配置、
  Token 统计、设备形态与坐标校准、信息同步。**尚无可用凭据时自动展开**，从主页「打开设置」过来的人直接看到要填的项。
- 每个输入框上方加常驻标签（框内提示字在输入后就消失，老人记不住）。
- 「重置」Token 计数新增确认。全部 id、`Prefs` 读写不变。

### 登录页 `activity_login.xml` + `LoginActivity`

- 手机用适老化新布局，手表用原布局 `activity_login_watch.xml`（两套 id 一致，门禁 E-1 校验）。
- 标签常驻；新增「显示密钥，方便核对」（`cbShowKey`，只切换显示方式）；「登录」是唯一实心主按钮。
- 消息区改为语义色底块（原浅红 / 浅绿字在浅底上对比度不足）。

### 充值页、语音召唤抽屉

- 充值页：同一任务流（① Key → ② 单模型 → ③ 官方购买 → 状态），换适老化令牌；动态生成的档位卡片同步换令牌。
- 语音召唤：召唤即开始听，最大按钮是「说完了」；识别失败只给可执行的一句话，技术原因进 logcat。

### 悬浮层 `OverlayController`

手机形态下卡片与控制面板字号约 ×1.4（不低于 18sp）、可点控件 ≥ 60dp，提问卡片按钮改竖排；
白卡片上的「停止 / 拒绝 / 跳过」改深色字。底部进度胶囊不可点且会进入截图，只适度放大（13→16sp）。
窗口类型、触摸标志、显示 / 撤下时机均未改动。
